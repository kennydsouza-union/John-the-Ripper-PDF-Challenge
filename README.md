# CTF Challenge: Password-Protected PDF Recovery

## Overview
During today's CTF challenge, I encountered a password-protected PDF file. Using John the Ripper in an authorized environment, I successfully recovered the password, accessed the document, and captured the flag.

## Objective
Understand the security of password-protected PDF files and successfully complete the challenge by recovering access to the protected document.

## Tool Used
- John the Ripper

## Key Learning Outcomes
- Understanding password-protected PDF files
- Learning about password strength and file security
- Exploring password recovery in a controlled CTF environment
- Understanding why weak passwords can undermine file protection
- Improving practical cybersecurity and problem-solving skills

## Security Takeaway
Password protection alone does not guarantee absolute security. Weak or predictable passwords can make protected files vulnerable to recovery attempts.

However, strong encryption combined with a long, unique password significantly improves security. Encrypted files are not automatically easy to crack—their security depends on the encryption scheme, password strength, and implementation.
